# Design Director — 0.2.1 delta

**Scope:** delta re-audit of the design-specificity / visual-language dimension against the fixed 0.2.1 tree (HEAD `90d81a9`, fix `ed3ee6c`). Read-only source review plus the 0.2.1 evidence set `docs/qa/evidence/ui-021/` (18 screenshots, Android 16 emulator, 1080×2400 @420 dpi, Arabic RTL except `home-empty-en.png`). No adb, no build, no app/QA edits. Contrast ratios are **computed** from token hex in sRGB; chrome heights are **computed** from declared dp plus M3 defaults. Visual claims name their screenshot.

**0.2.0 P0 check:** the landscape empty-state P0 is gone — `home-empty-ar-landscape.png` fits icon, title, body, CTA and footnote above the navigation bar, and `home-empty-ar-landscape-font200-scrolled.png` scrolls instead of clipping (`Common.kt:119-145`, `WorkbenchScreen.kt:186-230`). No new P0/P1 visual regression appears in the evidence set.

## Verdict

0.2.1 is the first release with a design *system*: every M3 colour role is authored, cards finally have a hairline, Arabic has its own rhythm, a sand selection accent exists, the dark launch no longer flashes white and the OCR dead end is gone. Specificity moves **1 → 2 /4** — a designer can now recognise a Sigha skin. But 0.2.1 authored the system, not the *identity*: the mark is still a stock `SwapHoriz` glyph, the Arabic voice is still the OEM's font, the launcher is still off-palette gold, and the new rules are unwritten — one commit after the card fix, History and Queue already use a different card. Composition is unchanged where it matters: two stacked bottom bars and a below-the-fold target choice survive, and the new hint makes the stacked chrome 26 dp taller in exactly the state that needs the room.

## Dimension judgement and re-score

**Moved the right way:** the palette is a scheme now, not an accent — mist page, ink text, emerald action, sand selection, green-grey container ramp — and it survives dark (`home-empty-ar-dark.png`). Shape is authored (6→28 dp), cards read as cards, the empty state is composed for this product (product title, on-device promise as body, supported-formats footnote, compact landscape) and the Arabic surface has its own leading and tracking. A designer would now recognise a Sigha skin: this is no longer stock M3 with a green button.

**Still category-interchangeable:** remove the word صيغة and the first screen has no mark — its largest element is a stock swap glyph in a mint square, the same glyph as the selected tab and the CTA; the launcher uses a different gold; the typeface is whatever the phone ships; and the differentiator (offline/privacy) is one sentence in the empty state with no visual token while `offline_badge` remains unrendered. The system is also unwritten, so its edges are already decaying: cards fixed in one screen only (R1), sand carrying two meanings (R2).

**Specificity re-score: 2/4** (was 1/4). The scheme, shape ramp, Arabic rhythm and a real selection accent earn the second point: there is now a coherent visual language to recognise. The third point needs the identity layer the baseline asked for — an authored mark and wordmark with a monochrome launcher, a bundled Arabic face, a persistent privacy token — plus one documented card/row language. Those are design decisions, not token edits.
