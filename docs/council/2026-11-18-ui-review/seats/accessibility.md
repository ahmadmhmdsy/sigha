# Accessibility — 0.2.1 delta re-audit

**Seat:** accessibility (a11y-auditor). **Date:** 2026-11-18. **Tree:** 0.2.1 fix pass, `ed3ee6c`.
**Baseline:** `docs/council/2026-11-17-ui-review/seats/accessibility.md` — 14 findings (4×P1, 8×P2, 2×P3), five sub-dimensions 13/20. This file is the delta only.

**Method.** Read-only: the UI sources, `Theme.kt`/`Color.kt`/`Type.kt`, string resources, the Lead's evidence set (`docs/qa/evidence/ui-021/`, 18 PNGs), `docs/qa/verification.md` §7.1 and `verify-20261117-231022.json`. No emulator, adb or TalkBack (the Lead owns the device) — runtime behaviour is marked *inferred*. Contrast is recomputed from authored hex. Cards are now flat `surfaceContainerLow` **#F7FAF8** with a hairline border (`SighaCard.kt:24-31`); Queue/History rows are `surface` + `tonalElevation = 1.dp`, i.e. M3 `surfaceColorAtElevation(1.dp)` = 5.12 % of `surfaceTint` (= primary) over `surface` = **#EFF6F4** (the baseline's card tone). Solid areas sampled from the PNGs match the tokens exactly (card #F7FAF8, tonal #EFF4F1, dark background #0F1513, button #0E7C66, Done pill #B8EBDD, selected chip #FFDF9E).

## 3. Dimension judgement, 0.2.1

| Dimension | Baseline | 0.2.1 | Basis |
|---|---|---|---|
| Screen-reader support | 2/4 | **3/4** | From 0 explicit semantics to: 4 `semantics {}` sites, 1 `mergeDescendants` row, 1 `clearAndSetSemantics`, 2 `stateDescription`, `heading()` in one shared component (14 call sites), 4 `Role.`, 3 `selectableGroup`, a named slider, merged progress, and route direction. Held at 3 by announcement quality (N3–N6), the unannotated policy document (#8) and the absence of any live region. |
| Contrast | 2/4 | **4/4** | Every text pair passes AA in both themes: floor 4.79 (primary 14 sp on the background), onSurfaceVariant 6.41–6.78, error 5.89–6.15, badges 12.00, pills 5.83–13.35, dark ≥7.08. Meaningful non-text: outline 4.28, primary 4.88, dark 5.64–10.70. Only decorative hairlines (1.55 light / 1.91 dark) and M3's inactive progress/slider track (1.16) are below 3:1 — neither carries information alone (value text and the filled indicator do). |
| Text scaling | 3/4 | **3/4** | Both baseline blockers are gone (single-line bar; uncapped failure reason) and the empty state scrolls at 2.0. Not raised: the 2.0 evidence is one landscape empty-state frame — no populated list, dialog or OCR card was captured at 2.0. |
| Touch targets | 4/4 | **4/4** | Unchanged and clean: every affordance is an M3 component; bytecode confirms clickable `Surface` (Button/TextButton), `RadioButton`, `Slider` and `IconButton` apply `minimumInteractiveComponentSize`, so even the zero-padding "Show details" `TextButton` (`QueueScreen.kt:248-258`) keeps a 48 dp target. |
| Focus order | 2/4 | **3/4** | Radio double-stops and the naked progress row are gone. Still open: History's redundant open target (#14), the CTA in a bottom bar composed after all content, and 0 `onClickLabel` / 0 `traversalIndex` anywhere. |

**Sub-dimension total: 13/20 → 18/20.** Verdict: the accessibility half of the 0.2.1 pass **landed**. The vocabulary changed from "labels only" to "labels + state": a TalkBack user can now hear selection, slider values, section headings, per-file progress and source→target direction. What remains is not design work — it is (a) one announcement-hygiene pass (N3–N6: prefer `clearAndSetSemantics` when replacing visible text, and drop state that repeats text), (b) two semantics fixes on 0.2.1's own new UI (N1, N2), and (c) #14's duplicated history target. No P1 remains; the dimension is no longer a screen-reader ship blocker, but it is still **not verified** by a TalkBack pass.

## 4. Limits of this review

- **Inferred, not heard.** Every "announces" / "focus stop" / "reads twice" statement is derived from Compose semantics and material3 1.3.1 bytecode; §7.1 states TalkBack speech was not exercised. A device pass should check: status-pill announcement in Queue/History, the Queue route row, the pages error, the disabled-Convert hint, and chip groups.
- **Curated evidence.** 18 PNGs: no dark Queue/History, no populated screen at 2.0, no dialog at 2.0; `home-empty-ar-dark.png` is the only dark frame with app chrome.
- **Contrast** is computed from authored tokens with the documented M3 compositing; solid areas sampled from the PNGs matched the tokens, but glyph pixels were not rasterised — the values are token ratios, not measured rasters.
- **Not checked:** animation/reduced-motion, high-contrast and colour-correction modes, OEM skins, API 26–28, and real TTS output.
- Lint's gate run has 0 errors (`verification.md` §3/§6) but the archived JSON does not itemise accessibility issues and Android lint cannot check Compose semantics — absence of warnings is not evidence.
- Carried from the baseline and still true: licence bodies are English-only with no "this text is English" cue, and raw engine diagnostics stay English by design (§8.7).
- Other seats' 2026-11-18 files were not read; `app/**` was not modified.
